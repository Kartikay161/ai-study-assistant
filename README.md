# AI Study Assistant

An open-source AI-powered study assistant designed to help students
summarize notes, generate study questions, and create flashcards.

## Features

- 📝 Note summarization
- ❓ Study question generation
- 🗂️ Flashcard creation
- 🐍 Written in Python
- 🔓 Open source
